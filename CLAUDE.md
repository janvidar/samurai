## Code style
- Never write comments in code that is otherwise not commented.
- Never write commends about what the code used to look like or do.
- Follow the same commenting style that is already there.
- Prefer ideomatic modern C++20 over older C-style C++.

## Git
- Always write git commit messages as a single sentence, one line.
- Never include the Co-Authored by
- When merging to master, always use fast-forward rebases.
- Never push unless explicitly asked to do so.
